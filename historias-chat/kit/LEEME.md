# Kit de Claude Code · Historias de Chat Hesloy

Cómo se usa, paso a paso:

1. Descomprime este ZIP en una carpeta de tu Desktop (por ejemplo `Historias-Hesloy`). Abre Claude Code en esa carpeta: leerá `CLAUDE.md` solo.
2. Pasa la foto del producto al cuaderno de Gemini "Hesloy · Historias de Chat". Te devuelve un bloque llamado PROMPT PARA CLAUDE CODE.
3. Guarda la misma foto en la carpeta `imagenes/` de este kit (nombre simple, sin espacios: `azzaro-intense.jpg`).
4. Pega el bloque en Claude Code. Lo primero que hará es buscar skills de diseño y decirte cuáles usará. Si necesita instalar algo, te preguntará.
5. Revisa el Studio en el navegador. Cuando te guste, escribe "aprobado" y renderiza.
6. Recibes MP4, póster PNG y el ZIP del proyecto. Anota el cierre en `BITACORA-PRODUCTOS.md` (y en la copia del cuaderno de Gemini).
